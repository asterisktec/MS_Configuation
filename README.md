# WellPass Monitoring Station Configuration

## Step 1. Clone or Pull


If this is a **NEW** installation, clone this repository with the following command:

```git clone https://github.com/asterisktec/MS_Configuration.git```

If this is an **existing Monitoring Station**, then simply pull the latest updates with:

```cd MS_Configuration```

```git pull```


## Step 2. Update


In the shell run

```cd MS_Configuration```

```sudo ./update.sh```

That will update all of the files with the most current version and will not change the email settings.



That's it! Once you've done that, reboot and relax.
